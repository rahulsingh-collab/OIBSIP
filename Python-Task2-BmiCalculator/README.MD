# BMI Calculator

A simple **BMI (Body Mass Index) Calculator** developed using **Python** as part of my **Oasis Infobyte Python Programming Internship – Task 2**.

## 📌 Project Description

This project calculates a person's Body Mass Index (BMI) based on their **weight in kilograms** and **height in meters**. After calculating the BMI, the program displays the corresponding BMI category.

## ✨ Features

* Takes weight as user input
* Takes height as user input
* Calculates BMI using the standard formula
* Displays BMI up to two decimal places
* Shows the corresponding BMI category
* Simple and beginner-friendly Python program

## 🛠️ Technologies Used

* **Python**
* **Conditional Statements**
* **User Input**
* **Arithmetic Operations**

## 🧮 BMI Formula

**BMI = Weight (kg) / Height² (m²)**

## 📊 BMI Categories

| BMI Range   | Category      |
| ----------- | ------------- |
| Below 18.5  | Underweight   |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9   | Overweight    |
| 30 or above | Obesity       |

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Open the project folder in VS Code or any Python-supported IDE.
3. Open the terminal.
4. Run the following command:

```bash
python bmi_calculator.py
```

5. Enter your weight and height when prompted.
