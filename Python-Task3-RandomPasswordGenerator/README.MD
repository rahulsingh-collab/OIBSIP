# Random Password Generator

A simple and secure **Random Password Generator** developed using **Python** as part of my **Oasis Infobyte Python Programming Internship – Task 3**.

## 📌 Project Description

This project generates a random password based on the length provided by the user. It uses a combination of **uppercase letters, lowercase letters, numbers, and special characters** to create a random password.

The project demonstrates the use of Python's built-in `random` and `string` modules.

## ✨ Features

* User can specify the password length
* Generates passwords randomly
* Includes uppercase letters
* Includes lowercase letters
* Includes numbers
* Includes special characters
* Simple command-line interface
* Beginner-friendly Python project

## 🛠️ Technologies Used

* **Python**
* `random` module
* `string` module
* Command Line Interface (CLI)

## ⚙️ How It Works

1. The user enters the required password length.
2. The program creates a character set containing:

   * Uppercase letters
   * Lowercase letters
   * Digits
   * Special characters
3. Python's `random` module randomly selects characters.
4. The selected characters are combined to create the password.
5. The generated password is displayed in the terminal.
