# Voice Assistant

## Objective

A Python-based voice assistant that listens to spoken commands and responds using voice.

## Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* datetime
* webbrowser

## Features

* Voice input through microphone
* Greeting response
* Current time
* Current date
* Google web search
* Text-to-speech response
* Error handling for unclear commands
* Exit command

## How to Run

1. Install required libraries:

```bash
pip install SpeechRecognition pyttsx3 PyAudio
```

2. Run the program:

```bash
python voice_assistant.py
```

## Commands

* Hello / Hi
* What is the time?
* What is the date?
* Search Python tutorial
* Exit / Quit / Stop
